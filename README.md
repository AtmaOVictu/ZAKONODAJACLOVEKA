Zakon ni beseda oblasti. Zakon je tehtnica, s katero oblast meri sama sebe.

## Kaj meri naslov

**ZAKONODAJA ČLOVEKA** ni zakonodaja O človeku. Zakonodaja O človeku ureja človeka kakor predmet; ZAKONODAJA ČLOVEKA postavlja človeka kakor merilo: vsak predpis se tehta z obema rokama — kaj da dostojanstvu ∧ kaj mu vzame; denar na eni stranici, dobro — osebno ∧ posredno — na drugi.

**DISEMINACIJA AROGANCE** — hiša nosi pričo o aroganci: razširja njeno ime ∧ z merili jo razblinja. Aroganca je trditev brez tehtnice (⚠, nikoli ⊢).

- **preslikava korpusnih zakonov** (Beseda je Ne) na državne zakone: zakon ↔ tehtnica, z obema rokama.

- **ne cenzura bitij** — tehtnica meri besede z izmerami ∧ nikoli bitij; obe roki sta enako dostojanstveni.
